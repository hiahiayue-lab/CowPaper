# CowPaper 0.4.0

CowPaper 0.4.0 brings a more dependable workflow for organizing and reading your literature library.

## 文献库 PDF 管理

- 支持保留原文件、拷贝到文献库文件夹或移动到文献库文件夹。
- 支持按元数据生成文件名，并提供单篇整理、批量整理与文献库根目录迁移。

## 批量组织

- 使用 Cmd/Ctrl 多选与 Shift 范围选择文献。
- 批量加入或移除文集与 Library 标签。
- 将多篇文献直接拖放到文集或 Library 标签。

## PDF 导入识别

- 改进 DOI 与学术元数据的确定性识别。
- 没有 DOI 时提供可能重复文献的确认，避免模糊匹配自动合并。

## PDF 标注

- Inspector 提供高亮、下划线与批注查看、筛选及展开阅读。
- 改进 PDF 高亮/下划线原文提取，并支持后台读取、重启持久化与手动重新读取。
- 标注内容可在文献库搜索中检索。
- 无法可靠识别的原文保持为空，避免展示错误文本。

## Discovery

- 缺少公开摘要的论文仍可补齐中文标题。
- 改进当前论文批次的重新分析、队列恢复与停止本轮分析体验。
- 修正每日周期边界，确保当前论文范围与分析状态一致。
